Linux-Lab - A fun way to learn Linux

After a year of long work, we have created a web based platform to learn the Linux command line along with networking concepts. Users will learn the Linux command line in a fun, informative, and interactive enviroment. Our command line shell simulator was made from sratch in PHP. Although not entirely accurate, it delivers the educational content about Linux. This is the tool I wish I had when I was learning the commnand line and I hope you guys can enjoy!
